# 결정 인박스 (elonfeedback)

바쁜 사람이 **자기 결정을 미루지 않도록** 돕는 1인용 도구입니다. AI 어시스턴트(Claude Code 등)가
"이건 내가 정할 게 아니라 당신이 정할 일"인 순간을 만나면, 인라인으로 질문해 흐름을 끊는 대신
**보기 좋은 결정 페이지**를 당신의 웹사이트에 올립니다. 당신은 폰에서 편할 때 **번호를 탭하거나
마이크로 편하게 말해서**(자동으로 글로 바뀝니다) 답하면 되고, AI가 그 결정을 비동기로 이어받아 진행합니다.

- 여러 결정을 **한 페이지에서 쭉 내리며** 답할 수 있습니다.
- **토큰·비밀번호**는 종단간 암호화(E2E)되어 **당신 컴퓨터에서만** 열립니다(서버엔 암호문만).
- 파일·스크린샷 첨부, 마이크가 안 되는 환경에서는 텍스트 입력도 됩니다.

## 이건 각자 자기 인스턴스로 씁니다 (공용 서버 없음)

이 도구는 **당신의 AI 세션과 직접 연결**되기 때문에, 여러 사람이 한 서버를 공유하지 않습니다.
팀원이라면 이 저장소를 받아 **당신의 Vercel 계정에 당신만의 인스턴스**를 배포하세요. 데이터도, 접속
주소도, 잠금 PIN도 전부 당신 것입니다.

## 배포하기 → **[SETUP.md](./SETUP.md)** 를 보세요

가장 쉬운 길: 이 폴더에서 Claude Code를 열고 이렇게 말하면 AI가 Vercel 가입부터 키 입력까지 옆에서 이끌어줍니다.

> 이 폴더의 SETUP.md 보고 나만의 인스턴스로 배포해줘

직접 하려면 `node scripts/setup.mjs` 한 방이면 됩니다. 자세한 건 [SETUP.md](./SETUP.md).

**Claude Code 스킬로 받기:** [`skill/feedback-inbox-setup/SKILL.md`](./skill/feedback-inbox-setup/SKILL.md)
파일을 팀원의 `~/.claude/skills/feedback-inbox-setup/SKILL.md` 로 복사하면, 팀원이 자기 Claude Code에
"결정 인박스 깔아줘"라고만 해도 이 저장소를 받아 배포까지 이끌어줍니다.

## 구성

- **웹앱** (Next.js, Vercel 배포) — 대시보드 + 결정 페이지 + 답변 저장.
- **로컬 CLI** (`bin/elonfeedback`) — AI가 결정을 게시하고(`ask`) 답을 회수하며(`inbox`), 과거 결정을
  참고하고(`history`), 당신의 결정 성향 프로필을 관리합니다(`profile`, 반영은 항상 당신 승인 후에만).
- **인터페이스 계약**은 [CONTRACT.md](./CONTRACT.md)에 정의되어 있습니다.

비밀값(`.env`, PIN, 토큰)은 절대 커밋하지 마세요 — `.gitignore`가 기본적으로 막아 둡니다.
